AULA 3

Claude Code: a ferramenta do curso

Todo o desenvolvimento das aulas é feito com o Claude Code. Você vai ver o que ele faz, o que não faz e como trabalhar com regras para que ele ajude sem estragar o que já funciona.

Claude CodeLê o projeto, edita arquivos, roda comandos e testa, sempre pedindo permissão para o que é sensível.
Regras do projetoO arquivo CLAUDE.md diz o que pode mudar, o que está travado e exige backup antes de alterar.
Outras IAsCodex, Antigravity e outras: panorama do mercado. Conhecer é útil; no curso usamos só o Claude.

Checklist da Aula 3

Uma página com “O que o Claude Code faz” e “O que ele não faz”, e o primeiro CLAUDE.md do seu projeto.

Por que a FacilApp API SQL é essencial Ela separa as interfaces do banco, centraliza autenticação e operações SQL, documenta o contrato no Swagger e permite que HTMLs, aplicativos e IAs usem os dados sem receber as credenciais do servidor. No curso ela roda no seu computador, na porta 7777, com SQLite.
