O que muda entre desktop, web, mobile e Linux

A regra de negócio pode ser a mesma, mas a experiência, a implantação e os recursos são diferentes.

D

Desktop (Windows)

A FacilApp API SQL roda como serviço no computador da recepção, com impressão da ficha e do recibo na térmica e banco na rede local.

C# / .NET 10 · Windows Service · PowerShell · ESC/POS · SQLite / SQL Server

W

Web

As telas abrem no navegador e falam com a API por REST e JSON. Atualização centralizada; domínio e HTTPS pelo Cloudflare.

HTML · CSS · JavaScript · APIs REST · Cloudflare

M

Mobile (Android)

App Android que abre as mesmas telas e usa câmera, toque e conexão instável do celular; mesmo login e mesma API.

.NET 10 Android · APK assinado · HTML/JS · APIs REST

L

Servidor (Linux)

A mesma API em produção na nuvem, atrás do Nginx com HTTPS, com o banco PostgreSQL e o código versionado no Git.

Ubuntu · Nginx · .NET 10 · PostgreSQL · Git

O que permanece

  • Regras de negócio.
  • Modelo dos dados.
  • Contratos da API.
  • Validações do servidor.
  • Identidade e permissões.

O ecossistema FacilApp: linguagens e ferramentas

Só o que é usado hoje nos sistemas FacilApp, no Windows e no Linux.

C# / .NET 10As APIs, os apps Android, o Abridor Windows e a FacilApp Print.
JavaScriptAs telas, sem framework, com SQL.js, avisos.js e o motor de ticket.
HTML e CSSUma tela por arquivo .html, o tema único TemaFacilApp.css e um CSS separado para o celular.
PostgreSQL e SQLitePostgreSQL é a produção, com um banco por cliente; SQLite é o ambiente local e as filas.
APIs RESTA API SQL, a API Fiscal, a API de impressão (porta 4000) e o /api/js/.
Nginx e LinuxA VPS serve os sites e repassa as chamadas para as APIs, com o Cloudflare na frente.
Windows ServicesA Print e as APIs nas máquinas dos clientes. Firewall e serviços se aplicam por scripts .ps1: a IA escreve, você revisa e roda.
Impressão ESC/POSTickets, fichas e recibos na impressora térmica, pela FacilApp Print.
CloudflareDomínio, HTTPS e cache na frente da VPS. Publicou? Confira com ?x=aleatório na URL.
GitVersão de cada mudança, com backup antes de alterar.

Um ecossistema, dois sistemas operacionais

A FacilApp API SQL é escrita em C# no .NET 10. No Windows roda como serviço, instalada e atualizada por scripts PowerShell. No Linux roda no Ubuntu (compatível com o .NET 10), com o nginx na frente publicando o HTTPS. As telas em HTML, CSS e JavaScript são as mesmas nos dois.

A API como ponto comum

A FacilApp API SQL permite que as telas web, o celular e o computador da recepção compartilhem autenticação, usuários, menus e operações SQL por um contrato HTTP documentado no Swagger.

Como a IA ajuda

  • Mapeia regras escondidas.
  • Escreve C#, JavaScript e PowerShell no padrão do projeto.
  • Compara implementações.
  • Produz testes de equivalência.

Modernizando uma solução existente com ajuda da IA

Modernização segura acontece por etapas verificáveis, não por uma substituição total sem controle.

InventariarTelas, dados e integrações
ProtegerBackup e testes atuais
SepararRegra, dados e interface
SubstituirUma parte por vez
CompararResultado antigo e novo

Estratégias

  • Encapsular o legado atrás de uma API.
  • Criar nova interface sobre a mesma regra.
  • Migrar uma rotina de cada vez.
  • Manter convivência temporária controlada.
  • Retirar o antigo somente depois da validação.

Cuidados

Não envie segredos para a IA, não altere dados reais durante testes e não remova o caminho anterior sem backup e evidência de equivalência.

PROMPT DE MODERNIZAÇÃO
Analise este módulo existente sem modificá-lo. Produza inventário de telas, regras, tabelas, integrações e dependências. Proponha uma modernização incremental com pontos de rollback. Para a primeira etapa, crie testes que registrem o comportamento atual antes de implementar a substituição.

Projeto prático em mais de uma plataforma

Compartilhe dados e regras na API, adaptando apenas a experiência de cada dispositivo.

API + SQLiteAutenticação, regras, dados e contrato comum.
Interface webBrowse completo para administração e escritório.
Interface mobileConsulta e atualização rápida para uso em campo.

Projeto sugerido

FastPousada: reservas e cadastros completos no computador, mapa de ocupação responsivo na web e check-in pelo celular na recepção. Todos usam a mesma FacilApp API SQL e o mesmo banco SQLite.

Teste de equivalência

  • Registro criado em uma plataforma aparece nas outras.
  • Permissões produzem o mesmo resultado.
  • Validações são aplicadas pela API.
  • Conflitos e falhas de rede são tratados.
ROTEIRO DO PROJETO
1. Definir RESERVAS e as regras compartilhadas (datas, quarto ocupado, check-in).
2. Criar as tabelas no SQLite e os endpoints na FacilApp API SQL.
3. Implementar o browse web de Reservas com CRUD completo.
4. Implementar a tela de celular para check-in e consulta de ocupação.
5. Instalar a API como Windows Service no computador da recepção e publicar no Ubuntu com nginx.
6. Executar testes cruzados nas três interfaces.

Entrega do módulo

Apresente duas interfaces utilizando a mesma API. Demonstre uma reserva criada no computador e o check-in feito pelo celular, com o mapa de ocupação atualizado.
