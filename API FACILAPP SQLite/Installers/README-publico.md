# Curso Programação 100% IA — FastPousada

Material completo do curso **Programação 100% IA** da FacilApp: o sistema FastPousada, a FacilApp API SQL
(.NET 10 + SQLite), as telas em HTML/CSS/JavaScript, os dashboards de cada módulo e os kits FacilAppDoc e
FacilAppPlanilha. Todo o desenvolvimento é feito com o Claude Code.

## Instalar

Baixe o instalador na página **[Releases](../../releases/latest)** e execute como administrador (Windows 10/11, 64 bits).

O instalador:

- copia o curso para `C:\CURSO` (a pasta pode ser trocada);
- instala a FacilApp API SQL como serviço do Windows na porta **7777** (já com o .NET 10 embutido, não precisa instalar nada);
- cria os atalhos do menu do curso e da bandeja da API.

Depois de instalar, abra o **Menu do Curso (FastPousada)** e entre com o usuário de estudo `facilapp`, senha `1`.
